ROMAJI IS BORN
2026-10-08FACT

ROMAJI — Japanese ↔ Romaji, with English & Indonesian meaning

Project lahir dari kebutuhan sederhana: mencari bentuk alfabet Latin dari kata Jepang tanpa harus lebih dulu tahu bahwa istilahnya adalah “romaji”. Arah produk disepakati sebagai EN/ID ↔ Japanese + Romaji, ditambah buku besar dictionary yang diindeks berdasarkan Romaji.

2026-10-09SUMMARY

UI Reliability — Theme and Navigation Repair

Setelah pengujian di browser Android menunjukkan light theme yang terlalu pudar dan header navigasi yang menghilang saat berpindah bagian, perbaikan difokuskan pada konsistensi permukaan warna dan perilaku sticky header. Release v0.3.1 mencatat perbaikan tersebut sekaligus menegakkan kembali sinkronisasi dokumentasi dan validasi ZIP final.

2026-10-09SUMMARY

Universal Translator Input — Auto-detect and Adaptive Results

Translator KAMUSORA dikembangkan dari tiga mode input manual menjadi satu form yang mencoba mengenali Bahasa Indonesia, English, Romaji, dan input bertulisan Jepang. Banner deteksi terpisah dihilangkan karena contoh input sudah ditampilkan pada placeholder. Hasil tetap memasangkan tulisan Jepang, Romaji, dan arti yang tersedia dari dataset lokal; deteksi bersifat heuristik dan cakupan frasa tetap terbatas.

Evidence: implementasi index.html dan rilis v0.3.2.

2026-10-09SUMMARY

Translator Interaction Reliability — Adaptive Results and Mobile Submit

Release v0.3.3 memperjelas hasil berdasarkan bentuk input, menyembunyikan panel hasil sebelum pencarian, dan menambahkan saran typo yang dipilih dari dataset lokal. Enter kini mengirim pencarian sementara Shift+Enter mempertahankan baris baru; pada mobile, keyboard ditutup dan panel hasil dibawa ke area pandang. Dataset tidak diperluas pada milestone ini agar perubahan interaksi dapat diuji terpisah.

Evidence: perubahan index.html, tests/test_translator_interactions.py, dan release v0.3.3.

2026-10-09SUMMARY

Exact-Match-First Results — Related Phrases and Dataset Expansion

Release v0.3.4 mempertahankan exact match sebagai hasil utama, lalu menampilkan maksimal empat entry terkait yang dideduplikasi berdasarkan grup relasi eksplisit. Setiap kartu terkait menampilkan tulisan Jepang, Romaji lengkap, arti English/Indonesia, dan kontrol salin. Dataset lokal juga diperluas dengan kosakata sehari-hari serta variasi frasa, tanpa API eksternal; bentuk kasual arigatou dipisahkan dari bentuk sopan arigatou gozaimasu.

Evidence: perubahan index.html, tests/test_translator_auto_detect.py, tests/test_translator_interactions.py, dan release v0.3.4.

2026-10-09SUMMARY

Release Archive Hygiene — Preventing Nested ZIP Bundles

Review setelah pengiriman v0.3.4 menemukan bahwa paket distribusi ikut membawa arsip ZIP rilis lama dan checkpoint backup. Builder kini mengecualikan file ZIP dari payload rilis, sedangkan preflight menolak nested archive agar ukuran paket tetap wajar dan artefak tidak berulang membesar setiap kali dibangun. Versi produk tetap 0.3.4 karena ini koreksi packaging, bukan perubahan fitur.

Evidence: scripts/build_release.py, tests/release_preflight.py, dan tests/test_release_preflight.py.

2026-10-09SUMMARY

Universal Related Results — Contextual Phrase Discovery

Release v0.3.5 memperluas pilihan frasa terkait agar berlaku lintas input English, Indonesia, dan Romaji. Kata dasar seperti “good” mempertahankan hasil kamus exact match sambil menampilkan opsi frasa yang dapat dipilih; kata kontekstual seperti “selamat” meminta pengguna memilih frasa yang dimaksud daripada memaksakan satu terjemahan. Seluruh opsi bersumber dari dataset lokal, dideduplikasi, dibatasi jumlahnya, dan membuka alur pencarian exact-match yang sama saat dipilih.

Evidence: index.html, tests/test_universal_related_results.py, docs/PLAN-v0.3.5.md, dan release v0.3.5.

2026-10-09SUMMARY

Universal Auto-Correction — Hybrid Word, Phrase, and Sentence Repair

Release v0.3.6 menambahkan koreksi lokal hybrid untuk input English, Indonesia, Romaji, dan tulisan Jepang. Input valid tetap diprioritaskan; typo yang cocok kuat dengan dataset atau pola kalimat lokal dapat dikoreksi otomatis dengan indikator asal teks dan opsi undo, sementara kasus ambigu meminta pengguna memilih saran tanpa mengganti teks asli. Fitur tetap offline-first, berbasis dataset/heuristik lokal, dan tidak mengirim teks ke layanan eksternal. Dukungan kalimat dibatasi pada pola lokal dan kandidat yang tersedia, sehingga bukan klaim grammar checker universal.

Evidence: index.html, tests/test_universal_auto_correction.py, docs/PLAN-v0.3.6.md, dan release v0.3.6.
